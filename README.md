# AuraGram

عميل تيليجرام لسطح المكتب على ويندوز، مصمم للعمل بلوحة المفاتيح وقارئات الشاشة.
مكتوب بلغة بايثون باستخدام wxPython للواجهة و Telethon للاتصال بتيليجرام.

من تطوير Omnya Technology.

الإصدار الحالي وما فيه: [CHANGELOG.md](CHANGELOG.md).

## التشغيل من المصدر

يحتاج بايثون 3.11 أو أحدث.

```bash
pip install -r requirements.txt
python main.py
```

في أول تشغيل يطلب البرنامج رقم ومفتاح تطبيق تيليجرام (`api_id` و `api_hash`)،
وتحصل عليهما مجاناً من https://my.telegram.org في قسم API development tools.
بعدها يطلب رقم هاتفك والكود لتسجيل الدخول.

اضغط F1 داخل البرنامج لقائمة اختصارات لوحة المفاتيح.

## الاختبارات

```bash
python -m unittest discover -s tests -t .
```

تعمل على تيليجرام وهمي في الذاكرة: لا تتصل بالإنترنت، ولا تلمس جلستك، ولا تفتح نوافذ.

## بناء البرنامج وملف التثبيت

```bash
python build.py
```

يشغّل الاختبارات، ثم يبني البرنامج في `dist/AuraGram`، ثم يبني ملف التثبيت
`dist/AuraGram-Setup-<الإصدار>.exe`.

البناء يأخذ رقم ومفتاح التطبيق من `config.json` الموجود في المشروع ويضعهما داخل
البرنامج، فلا تطلبهما النسخة المثبتة من المستخدم. جلسة الحساب لا تدخل في البناء
أبداً. تنبيه: من يحصل على ملف التثبيت يستطيع استخراج المفتاح منه، وهذا حال كل
تطبيقات تيليجرام المنشورة.

يمكن أيضاً فتح `installer.iss` في Inno Setup مباشرة وبناؤه من هناك بعد تشغيل
`python build.py`؛ رقم الإصدار واسم الناشر مكتوبان فيه.

- بناء البرنامج يحتاج PyInstaller: `pip install pyinstaller`
- ملف التثبيت يحتاج Inno Setup 6 من https://jrsoftware.org/isinfo.php ،
  وبدونه يُبنى البرنامج فقط.

## التثبيت والإزالة

ملف التثبيت يحتاج صلاحيات المدير، ويثبّت البرنامج لكل مستخدمي الجهاز في
`C:\Program Files\AuraGram`. يعرض إنشاء اختصار على سطح المكتب وتشغيل البرنامج في
الخلفية مع بدء ويندوز.

بيانات كل مستخدم لا تُحفظ في Program Files، بل في مجلده الخاص:

- `%APPDATA%\AuraGram` (Roaming): الإعدادات، جلسة تيليجرام، وملف الأخطاء `auragram.log`.
  إذا ظهرت رسالة خطأ غير واضحة فتفاصيلها في هذا الملف.
- `Downloads\AuraGram`: الملفات التي نزّلها من المحادثات.

للإزالة: من «إزالة AuraGram» في قائمة ابدأ، أو من «التطبيقات» في إعدادات ويندوز.
الإزالة تغلق البرنامج إن كان يعمل في الخلفية، ثم تسأل هل تُحذف بيانات الحساب
والإعدادات أيضاً. الجواب الافتراضي «لا»، فتبقى الجلسة ولا يُطلب تسجيل الدخول عند
إعادة التثبيت. مجلد التنزيلات لا يُحذف في الحالتين.

## إصدار نسخة جديدة

1. غيّر `APP_VERSION` في `core/constants.py`.
2. أضف قسماً للإصدار في أعلى `CHANGELOG.md`.
3. شغّل الاختبارات والبناء.
4. ارفع ملف التثبيت، ثم حدّث ملف التحديثات (انظر «إشعار التحديث» أدناه) ليعرف المستخدمون.
5. احفظ التغييرات وضع وسماً:

```bash
git commit -am "Release 1.1.0"
git tag -a v1.1.0 -m "AuraGram 1.1.0"
```

## إشعار التحديث

البرنامج يبحث عن إصدار جديد عند فتحه ومن قائمة «مساعدة»، بقراءة ملف JSON صغير من
العنوان المكتوب في `UPDATE_INFO_URL` داخل `core/constants.py`. ما دام هذا العنوان
فارغاً فالبحث متوقف. ضع فيه عنوان `https` لملف بهذا الشكل:

```json
{
    "version": "1.2.0",
    "url": "https://example.org/AuraGram-Setup-1.2.0.exe",
    "notes": {"ar": "ما الجديد", "en": "What is new"}
}
```

`notes` اختياري. البرنامج لا ينزّل ولا يشغّل شيئاً بنفسه: يعرض رقم الإصدار ويفتح
العنوان في المتصفح إن وافق المستخدم، ولا يقبل إلا عناوين `https`.

## الخصوصية

- AuraGram يتصل بتيليجرام مباشرة (أو عبر البروكسي الذي يضعه المستخدم) ولا يمر بأي خادم
  يخص المطوّر. لا يجمع بيانات ولا إحصاءات استخدام.
- الجلسة والإعدادات وسجل الأخطاء تبقى على جهاز المستخدم في `%APPDATA%\AuraGram`.
- وصف الصور اختياري ومتوقف حتى يضع المستخدم مفتاح Gemini خاصاً به. عندها تُرسل إلى
  Google الصورة التي يطلب وصفها فقط، وقت الطلب. المفتاح وكلمة سر البروكسي يُحفظان في
  `settings.json` على الجهاز نصاً عادياً.
- تقرير المشكلة ملف يُحفظ على الجهاز ولا يُرسل تلقائياً؛ المستخدم هو من يرسله.

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `main.py` | نقطة البداية: نافذة الدخول، النافذة الرئيسية، والعمل في الخلفية |
| `core/` | الاتصال بتيليجرام، الإعدادات، الصوت، والثوابت |
| `ui/` | النوافذ. النافذة الرئيسية مقسمة حسب الوظيفة على عدة ملفات |
| `locales/ar.json` | كل نصوص الواجهة |
| `assets/` | الأيقونة والنغمات، وتُولَّد بـ `tools/make_assets.py` |
| `tests/` | الاختبارات |
| `build.py` و `installer.iss` | البناء وملف التثبيت |

## ملفات لا تُرفع إلى المستودع

هذه الملفات خاصة بك ومتجاهَلة في `.gitignore`. لا تشاركها مع أحد:

- `config.json`: رقم ومفتاح تطبيق تيليجرام.
- `auragram_session.session`: جلسة حسابك. من يحصل عليها يدخل حسابك بدون كود.
- `settings.json` و `downloads/`: إعداداتك والملفات التي نزّلتها.

عند التشغيل من المصدر تكون بجانب `main.py`. في النسخة المثبتة تكون في
`%APPDATA%\AuraGram`، والتنزيلات في `Downloads\AuraGram`.
